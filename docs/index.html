create-intellisense

Zero-dependency TypeScript declaration (index.d.ts) generator for JSON-driven NPM architectures.

The Ecosystem Story

In JSON-driven architectures, routes and schema transformations live in JSON specifications (source.json as truth, api.json as inspection allowlist). create-intellisense analyzes these specifications and automatically synthesizes strongly-typed TypeScript declarations without copy-pasting generators or maintaining hand-written types.

$ npx create-intellisense
STAGE 01

Scanner

Auto-detects active version folder (v1, v2, v7) from src/index.js.

STAGE 02

Parser

Loads api.json route allowlist and source.json domain tree.

STAGE 03

Synthesizer

Infers DTO interfaces and renders complete callable tree declarations.

STAGE 04

Writer

Resolves package.json's types field and writes production index.d.ts.
